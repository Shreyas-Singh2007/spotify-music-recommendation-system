# 🎵 Spotify Music Recommendation System

A hybrid music recommendation system that combines Content-Based Filtering and Collaborative Filtering to recommend Spotify tracks based on audio features, genres, and user preferences.

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- K-Means clustering
- Content-Based Recommendation
- Collaborative Filtering
- Model evaluation
- Data visualization

## Dataset
Spotify Tracks Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- SciPy

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Engineering
5. K-Means Clustering
6. Recommendation System
7. Model Evaluation

## Results
- RMSE: 0.9188
- MAE: 0.4967
- Precision@10: 1.0000
- Recall@10: 0.0023
